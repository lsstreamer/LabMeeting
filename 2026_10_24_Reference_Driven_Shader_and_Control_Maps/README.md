## 通过统一服务打开

在服务器上运行：

```bash
cd /home/sirui/workspace/LabMeeting
python3 serve.py --bind 0.0.0.0 --port 8000
```

访问首页 `http://localhost:8000/`，或者直接打开：

```text
http://localhost:8000/2026_10_24_Reference_Driven_Shader_and_Control_Maps/
```

直接以 `file://` 打开演示稿时，报告可以离线播放；实时评估入口沿用 `http://localhost:7870/`，需要相应服务或转发。

输入为已有三维模型（含原始材质和贴图）与目标风格参考图。主要输出是 Shader、参数配置及控制贴图；同时保留原始带材质模型，配套提供应用 Shader 后的渲染图片与视频。工作重点是着色表达的拟合与生成。

## 内容来源与标注

主线 Avatar03 与第 19 页的八个模型均已同步项目当前保存结果；多模型展示使用原生透明最终图。Avatar03 的相机候选使用本地 **DINOv3 ViT-B/16**；第四页相机拟合 IoU 为 **0.9471**。第五页不展示生成参考图的 IoU 数值。Avatar03 的阶段图、局部裁切、视频及其封面均同步当前输出。Avatar01–06、ice 与 lion 均使用当前 DINOv3 结果，作为辅助展示。处理与来源摘要见 `assets/result_snapshot.json`。

- 主线图片来自 ShaderNPR 项目已保存的 Avatar03 结果；其他模型图来自对应输出目录。图片来源记录在 `assets/sources.json`。
- 最终结果使用项目新导出的透明 PNG；原始风格参考直接使用 `reference_preprocess/reference_rgba.png`；整套汇报优先直接使用 `out` 中现成的透明输出；没有对应透明版本时，才用 `out` 的同帧遮罩或背景连通区域补透明通道，保留原图 RGB 像素。相机候选的多子图诊断拼图保留原样，以保留面板、标注和可读性。局部特写在页面内裁切，点击后显示完整原图；模型渲染未重新生成。
- BaseColor 图用于说明外观起点，不代表严格实验基线。
- `0.9471` 来自 `camera_alignment/pose_result.txt` 的 `final_iou`，属于轮廓重合度。
- S03 按汇报定义为 **边缘光优化**，可调颜色、强度、阈值与柔和度；当前默认关闭，Avatar03 未执行。原项目仍使用 `shading_detail_optimization` / `detail_refine` 的旧名称与配置，尚未同步更名和训练逻辑。
- Avatar03 使用原始 Part，共 14 个分区；P3-SAM 和 SAMPart3D 是项目支持的其他分区方式。
- 描边第二步的颜色 L1（0.1051 → 0.0381）来自该步骤保存的 `stats/step2/metrics.json`，只衡量匹配描边颜色，不能作为整体质量分数。
- 阶段图是顺序优化结果；严格消融与统一定量评价列为未来工作。
- 第 18 页直接使用项目最新的 1024 × 1024、24 帧 VP9 WebM 透明视频，保留原始透明通道，未经二次转码；封面为同一视频的透明 PNG 首帧。支持同时播放、暂停和回到开头，离页自动暂停。原项目文件未修改。
- 该汇报页播放静态结果与视频；第 20 页介绍的实时调参与 GPU 渲染能力属于原 ShaderNPR 项目的预览应用。
